# 体質別ダイエット診断 & 食事相談ツール

20問の質問で7つの体質タイプを診断し、あなたに合ったダイエット方法を提案します。また、今日食べたものをAIに相談できる食事相談ツールも搭載。

## 機能

- **体質診断ツール**: 20問の質問で7タイプを診断（ホルモン型・自律神経型・マインド型・代謝型・腸活型・食習慣型・栄養型）
- **食事相談AI**: Claude AIと対話して食事のアドバイスをもらえる

## 使い方

1. ブラウザでアクセス
2. 「体質診断」タブで20問に回答
3. 「食事相談」タブでClaude APIキーを設定してAIに相談

## APIキー

食事相談はAnthropicのClaude APIキーが必要です。
[Anthropic Console](https://console.anthropic.com/) から取得できます。
